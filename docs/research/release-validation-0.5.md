# v0.5 岗位定向作战包验收记录

> **状态：** 自动化发布候选检查通过；真实求职者试用仍待完成<br>
> **核验日期：** 2026-08-21<br>
> **适用范围：** v0.5 岗位定向方法、角色包、角色定向模拟、工作表、来源契约和导航

## 1. 本次要验证什么

v0.5 试图补上从“理解 FDE”到“针对一条真实 JD 组织证据和训练”的缺口。验收不以新增页数为目标，而检查读者能否沿一条明确路径完成：

```text
公开 JD
-> 事实与假设分栏
-> 主工程脊柱
-> D/A/E/G 证据矩阵
-> 角色专项练习
-> 第一次评分
-> 两个高风险行为重练
-> 第二次盲评
```

项目必须同时守住三条边界：不把公开岗位信号扩写成内部面试流程，不把设计练习包装成生产经历，不用未经验证的匹配率或通过率制造确定性。

## 4. 人工审阅重点

自动化检查不能判断内容是否真的帮助候选人变强。人工复核聚焦以下问题：

1. 角色包是否与现有岗位地图、学习计划、作品集和现场模板重复；
2. 每项建议是否能产生可展示产物，而不只是阅读任务；
3. 表格是否把复杂判断压缩成错误的二元规则；
4. 合成示例是否明确标注虚构，没有暗示真实公司或真实面经；
5. 工作表是否告诉读者何时使用，而不是要求形式化填满；
6. 岗位信号、面试假设和个人证据是否始终分开；
7. 外部来源改变或下线后，维护者是否知道怎样降级结论。
8. 候选人 brief 是否完全隔离主持人证据，主持人能否只按有效提问释放信息。

本轮审阅后保留了十次“有输出、评分、第二版”的训练闭环，没有增加机械匹配百分比，也没有把三类岗位写成互斥分类器。

## 5. 尚未验证的部分

以下事项明确未完成：

- 尚未由至少三位不同背景、正在求职的读者完整执行；
- 三套角色定向模拟尚未由独立主持人实际完整运行；
- 尚未观察读者能否在没有作者解释时正确使用 D/A/E/G；
- 尚未比较第一次与第二次盲评中哪些行为锚点真正改善；
- 尚未验证十次训练对不同面试时间窗口是否需要调整；
- 不具备也不声称任何面试通过率、录取率或薪酬提升证据。

因此 v0.5 当前是可检查、可练习、可维护的发布候选，不是已经完成效果验证的成熟训练产品。

最难理解的说明：

不得收集公司保密信息、真实面试题、面试官身份、个人敏感信息或付费材料。试用反馈用于修改说明、完成规则和训练顺序，不用于宣传通过率。

## 7. 发布判断

自动化与内部内容验收支持将 v0.5 作为公开候选版本进入 PR 复核。正式宣称该训练闭环经过外部验证之前，必须按照匿名试用协议完成 Roadmap 中的三人试用和至少一次独立主持，并修复任何需要作者口头解释的证据等级、释放规则或完成标准。
