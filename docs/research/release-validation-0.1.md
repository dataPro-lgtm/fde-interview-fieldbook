## 外部来源可访问性

并行 HTTP 检查中 14 个来源返回 200。两个 OpenAI Careers 链接对命令行客户端返回 403，但在同日通过浏览器抓取正常访问并核验内容。这被视为反自动化响应，不误报为失效链接。

外部链接不会作为每次 PR 的硬门禁，因为招聘网站可能限流、反爬或短时不可用。月度流程检查来源年龄，再由维护者人工复核语义变化。
