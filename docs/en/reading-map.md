## Choose by time

### Fifteen minutes

Read the [role map](role-map.md), write a target-role sentence, and score only evidence you can defend. Do not open a broad question bank until the target and top risk are clear.

### Sixty minutes

1. [Start here](start-here.md) — set target and baseline;
2. [Discovery](discovery.md) — write one mission before architecture;
3. [Portfolio evidence](portfolio-evidence.md) — repair one project story;
4. [Production AI](production-ai-2026.md) — identify one production-risk gap.

Output a one-page plan and one recorded answer, not a list of pages read.

### One week

Use the machine-checked [seven-day guided path](guided-practice.md):

- role and baseline;
- discovery and project evidence;
- coding or debugging in the target format;
- system design with a scored replay;
- production AI and security failure modes;
- one blind Field Case Lab;
- full mock, scoring, and two behavior changes.

The prose version with daily exits is in [evidence-first study plans](study-plans.md).
