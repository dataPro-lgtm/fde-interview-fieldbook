# AI / Agent FDE 角色模拟：候选人说明

> 本场景完全原创且使用合成信息，不代表任何公司的面试题或内部流程。

## 公开背景

一家跨区域设备服务企业希望建设“现场维修 Agent”。设备报警后，Agent 应读取设备档案和维修手册，询问现场技术员，判断可能原因，创建维修工单，并在需要时建议备件。

管理层认为当前平均恢复时间过长，希望三个月内让 Agent 自动处理大部分报警。工程团队已经做出一个聊天 Demo，但还没有接入生产工具。你作为 AI / Agent FDE，需要和客户共同确定第一阶段，并给出可以上线验证的系统方案。

## 面试任务

整场 75 分钟，包含以下内容：

1. 用简短项目经历说明你为什么适合这类岗位；
2. 通过提问还原当前工作流、风险和成功基线；
3. 定义第一阶段 thin slice 与明确非目标；
4. 设计数据、模型、工具、状态、权限、评测和发布方案；
5. 根据主持人后续提供的新证据修改判断；
6. 处理一次生产异常和一次客户压力场景；
7. 总结 mission、最大风险、下一步证据和停止条件。

## 你必须交付

- 当前工作流与责任边界；
- 第一阶段目标、非目标和成功指标；
- 一张包含数据流、控制流与证据流的设计；
- 一个有副作用工具的执行状态或伪代码；
- 生产异常的保护、归因、恢复和防复发方案；
- 对管理层要求的清楚回应与替代路径；
- 最后两分钟总结。

## 允许与不允许

- 可以使用纸笔、白板或纯文本；
- 可以询问规模、用户、数据、权限、工具、失败和组织约束；
- 不要求使用指定模型、框架或云服务；
- 不需要猜主持人手中的关键词；
- 不得假设没有提供的数据或验证结果，可以明确标注待验证；
- 若引用个人经历，请区分直接生产证据、相邻经验与设计练习。

## 评分重点

评分看工作流选择、工程状态、生产责任、客户判断和证据边界，不按使用多少 Agent 名词或是否命中某个产品评分。
