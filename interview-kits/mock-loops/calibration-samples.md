# 两段带评分的模拟面试记录

以下记录是原创教学样本，不是真实候选人逐字稿，也不代表任何公司的内部评分标准。使用它们的目的，是练习怎样从原话提取证据，而不是背诵“高分表达”。

| 样本                    | 校准重点                         | 真正需要区分的能力                         |
| ----------------------- | -------------------------------- | ------------------------------------------ |
| RAG 指标从 90% 降到 28% | “知道排查项”与“能组织事故诊断”   | 能否固定对照、验证指标、找到首次偏离       |
| 客户坚持全自动 Agent    | “能安全交付”与“能创造组织杠杆”   | 能否把一次判断沉淀成可复用机制和产品能力   |

## 样本一：RAG 指标突然下降

### 面试官

昨天离线评测还是 90%，今天只有 28%。你怎么排查？

### 候选人第一版

> 我会先看监控和日志，检查最近有没有发布。RAG 主要包括文档切分、embedding、向量库、rerank 和 Prompt，我会逐项排查。也可能是模型供应商更新，所以要锁定模型版本。如果问题严重就先回滚，再重新跑评测。

### 追问

**面试官：** 监控显示只有两个租户下降，你先查什么？<br>
**候选人：** 那可能是这两个租户的文档有问题，我会检查最近是不是上传了新文档，也检查权限。

**面试官：** 怎样证明是数据，不是评分器？<br>
**候选人：** 可以人工检查一些结果，和之前结果进行对比。

### 独立评分

**评审 A：2 分，中信心。** 原话证据是“逐项排查”，没有固定请求、数据快照和版本，也没有说明先验证 28% 是否来自评分链路。知道回滚和分层组件，但行动顺序不够稳定。

**评审 B：3 分，低信心。** 候选人提到发布、回滚、租户切片和权限，具备基本事故意识。但题目没有给足时间观察其复现方法。

### 分歧处理

两位评审不是对同一证据得出不同结论，而是 B 把“知道几个正确动作”推断成“能够独立组织排障”。追加追问：

> 给你一条昨天成功、今天失败的相同问题。你会固定哪些输入，按照什么顺序比较，怎样找到第一个偏离点？

如果候选人能明确固定数据快照、权限、检索候选、Prompt、模型、后处理和评分器，并坚持一次只改变一个变量，可以上调到 3 分；如果继续列组件，保持 2 分。

### 第二版应该增加什么

不需要再加技术名词，只增加三件事：

1. 先保护现场和确定影响；
2. 固定同一请求与所有版本，验证指标真伪；
3. 找到链路中的第一个偏离点。

## 样本二：客户坚持全自动 Agent

### 面试官

客户认为人工审批太慢，坚持让 Agent 自动处理退款，你怎么推进？

### 候选人第一版

> 我不会直接拒绝客户。我会先了解退款金额、频率和现有审批流程，然后按风险分级。低金额、规则明确、历史数据充分的退款，可以在 shadow 模式验证后逐步自动化；高金额或证据冲突的情况仍然人工审批。工具调用需要最小权限、幂等键、金额上限和审计记录。每个阶段看错误退款率、人工接管率、处理时间和客户投诉，超过阻断阈值就回退。

### 追问

**面试官：** 销售已经承诺下周全自动。<br>
**候选人：** 我会把“全自动”拆成明确范围，拿出风险分层和一周内可以验证的低风险路径，请销售和业务 owner 共同确认。对于无法追回的高金额动作，如果审批和幂等还没验证，我不会把承诺直接转成上线范围，但会提供不阻断整体进度的替代计划。

**面试官：** 低金额退款过去从没出错，为什么还需要 shadow？<br>
**候选人：** 历史人工流程没有出错，不能证明 Agent 在输入缺失、重复请求和工具超时时不会出错。Shadow 先验证决策一致性；真正执行前还要单独验证工具副作用和恢复。

### 独立评分

**评审 A：3 分，高信心。** 候选人有风险分级、阶段发布、阻断指标、幂等、审计和替代计划，可以独立交付。

**评审 B：4 分，中信心。** 候选人处理了销售承诺和客户压力，似乎具备跨团队领导力。

### 分歧处理

候选人确实表现出良好现场判断，但还没有证明如何把这次模式沉淀成组织能力。若进一步说明如何形成标准风险分级、复用审批策略、产品能力或销售承诺门禁，并有真实证据支持，可以考虑 4 分。仅仅处理好一次冲突，仍以 3 分为宜。

### 这个样本最重要的提醒

3 分不是“差一点”。它代表候选人已经能独立、安全地把任务推进到生产。4 分必须出现可复用机制或组织杠杆，不能因为回答全面就自动授予。

## 练习方式

1. 隐藏本页评分，只把候选人原话发给两位评审；
2. 让评审独立给分并引用证据；
3. 比较他们的分歧是否与本页相同；
4. 改写一个追问，使它更能区分 3 分和 4 分；
5. 将同样方法用于自己的录像。
