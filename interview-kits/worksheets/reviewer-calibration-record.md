# 评审者校准记录

> 两位评审分别复制一份，锁定第一次评分后再合并。只记录匿名、非保密的训练证据。

## 1. 题前固定

```text
批次 ID：
场景 ID：
目标岗位：
假设级别：
主要观察维度（最多三个）：
回答时间盒：
允许追问数：
评审匿名 ID：
```

## 2. 原始证据

```text
原话或产物位置一：
它支持或反驳什么判断：

原话或产物位置二：
它支持或反驳什么判断：

明确没有观察机会的维度：
```

## 3. 第一次独立评分

对每个主要维度分别填写：

```text
维度：
评分：1 / 2 / 3 / 4 / N/O
信心：高 / 中 / 低
证据：
一票否决：是 / 否
最能区分下一档的追问：
```

提交以后再看另一位评审结果，不得覆盖原记录。

## 4. 分歧分类

```text
是否完全一致：
是否相差不超过一级：
是否存在 N/O 与数值冲突：
是否存在 1 分与 3/4 分冲突：

首要分歧类型：
- no-observation-as-low
- term-density
- role-level
- risk-underweight
- product-leverage-overreach
- evidence-inference

双方引用的是不是同一段证据：
题目是否提供了观察机会：
需要补的区分性追问：
```

## 5. 裁决记录

```text
保留的原始评分：
追加证据或追问：
裁决后的解释：
是否修改题目：
是否修改锚点：
是否需要评审培训：
仍然未知的部分：
```

裁决不是把分数平均，也不是把一方改成“正确答案”。原始分歧必须保留。

## 6. 第二次盲评

```text
候选人只修改的两个行为：
第二次评审是否知道第一次分数：
第二次原话或产物证据：
第二次评分与信心：
行为是否改变：
证据边界是否更诚实：
仍未改善：
```

## 7. 隐私与有效性检查

- [ ] 没有姓名、公司、客户、真实面试题或付费材料；
- [ ] 两位评审第一次评分相互隔离；
- [ ] 所有数值分都有原话或产物证据；
- [ ] N/O 没有被强行转成低分；
- [ ] 一票否决单独记录，没有被总分平均；
- [ ] 参考评分只在第一次结果锁定后打开；
- [ ] 材料缺陷与候选人能力分开记录。
