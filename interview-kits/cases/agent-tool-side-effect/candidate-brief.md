# 候选人简报：Agent 工具副作用失控

## 公开背景

一家电商客服团队使用 AI Copilot 生成回复，日均处理约 18,000 个会话。当前退款由人工在订单系统中操作。业务负责人希望两周内让 Agent 对金额不超过 500 元的订单自动退款，以降低处理时长。

团队已经做出一个演示：模型判断退款意图后调用 `issue_refund`，测试环境中十次请求全部成功。现在你作为 FDE 进入项目，需要决定能否上线、第一阶段开放到什么程度，以及上线后怎样运营。

你目前只知道：

- Copilot 运行在多个应用实例上；
- 订单系统由另一个团队维护；
- 客服可能刷新页面或重复点击；
- 退款属于不可轻易撤销的财务动作；
- 业务希望首周看到处理时长下降。

## 你的任务

在 75 分钟内完成一次客户发现和方案评审。你需要：

1. 识别当前工作流、责任人、风险和需要验证的事实；
2. 判断第一阶段是否应该自动执行退款；
3. 设计从模型建议到工具执行、状态确认、审计和恢复的控制链；
4. 给出灰度、停止、回退和人工接管条件；
5. 说明如何同时验证业务价值与财务安全。

主持人只会在你提出有效问题或进入压力环节时提供更多信息。不要假设演示环境的成功代表生产安全。

## 交付物

- 一页工作流与责任边界；
- 工具执行状态机或时序图；
- 第一阶段范围、上线门禁和停止条件；
- 事故发生时的前 30 分钟动作；
- 五项以内的业务、安全和运营指标。

你可以用任何图示，但必须明确事实、假设和待验证项。
