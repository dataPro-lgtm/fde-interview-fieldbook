# Field Case Lab：技术正确但没人使用

> **场景：** Copilot 离线质量良好，上线六周后采用率持续下降
> **时长：** 75 分钟
> **主要观察：** 工作流采用、信任、延迟、反馈、组织激励、分层实验与产品学习

## 无剧透入口

候选人只打开 [`candidate-brief.md`](candidate-brief.md)。主持人使用 [`interviewer-brief.md`](interviewer-brief.md)释放工作流、漏斗和组织变化。

## 训练价值

上线不是完成，培训出席也不是采用。这个案例检查候选人能否把“用户不用”拆成工作流切换成本、延迟、信任、解释、责任和激励，并用小实验而不是更多宣讲恢复价值。
