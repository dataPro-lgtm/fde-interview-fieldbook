# Field Case Lab：AI 评测指标断崖式回归

> **场景：** 意图识别准确率从 90% 降到 28%
> **时长：** 75 分钟
> **主要观察：** 指标可信度、版本固定、分层归因、一次一变量实验、保护与发布门禁

## 无剧透入口

候选人只打开 [`candidate-brief.md`](candidate-brief.md)。主持人按 [`interviewer-brief.md`](interviewer-brief.md)释放版本矩阵、切片结果和压力条件。

## 训练价值

“数据漂移、prompt 变化或工具回归都有可能”只是原因清单。案例要求候选人固定请求和依赖版本，先验证指标与标签，再定位第一处偏离，并在根因未明时保护高风险流量。
