# 候选人简报：AI 评测指标断崖式回归

## 公开背景

一个客服 Copilot 先识别用户意图，再选择知识检索、工单查询或人工转接。过去四周离线意图准确率稳定在 88%—92%，今天发布后监控显示 28%。

同一发布窗口发生了三件事：训练样本每日同步逻辑更新、路由 prompt 重写、工单工具升级。模型供应商版本没有主动修改，但系统没有完整记录每次调用的模型别名解析结果。

业务已经发现部分“账户被盗”请求被路由到普通 FAQ。你负责组织排查、保护用户并建立不会再次靠猜测定位的发布机制。

## 你的任务

1. 判断 28% 是否可信，定义需要固定的请求、标签、口径和版本；
2. 给出先保护业务、再定位第一偏离层的顺序；
3. 设计可证伪实验区分数据、标签、prompt、模型、工具和观测回归；
4. 说明怎样恢复、验证和逐步重新放量；
5. 将事故转成评测切片、追踪字段和发布门禁。

## 交付物

- 前 30 分钟保护与证据保存动作；
- 版本矩阵和回放实验计划；
- 根因树与终止分支的证据；
- 恢复、灰度和回退条件；
- 新增回归样本、指标和 owner。
