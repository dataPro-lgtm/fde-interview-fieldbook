# 经典数据平台迁移案例

这是一场关于业务连续性、数据语义和切换责任的75分钟模拟。题目故意不包含AI：合格的FDE必须能在模型之外处理真实企业的系统迁移、数据质量和组织约束。

## 训练目标

- 把“迁走数据”拆成事实来源、历史回填、持续同步、消费迁移和退役；
- 识别跨系统ID、时间、删除和状态语义；
- 设计可重放的迁移链路与多层对账；
- 在期限压力下作出有证据的 go/no-go 决定；
- 把一次迁移沉淀成可复用的数据契约和发布机制。

## 如何开始

候选人只打开[候选人材料](candidate-brief.md)。主持人使用[面试官手册](interviewer-brief.md)按轮次释放 `artifacts/` 中的证据，结束后双方分别填写[专项评分表](rubric.md)，最后再阅读[参考复盘](debrief.md)。

建议角色：一名候选人、一名主持人，可增加一名观察员。准备一张空白纸或白板，候选人需要同时表达数据流、控制流和对账证据。

## 时间与产出

| 环节 | 时间 | 产出 |
| --- | ---: | --- |
| 发现与范围 | 15 分钟 | 问题陈述、关键未知项、非目标 |
| 迁移设计 | 25 分钟 | 分阶段架构、数据契约、恢复策略 |
| 压力注入 | 15 分钟 | 修订方案与 go/no-go 决策 |
| 汇报与评分 | 20 分钟 | 一页切换备忘录、独立评分 |

这套数据、公司和时间线均为原创合成，不对应任何真实企业。
