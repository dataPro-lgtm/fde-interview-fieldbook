# Field Case Lab：连接器从定制走向产品能力

> **场景：** 五个客户连接器形成分叉，升级和恢复越来越慢
> **时长：** 75 分钟
> **主要观察：** 契约核心、源适配、版本兼容、数据语义、运营面、迁移和产品化边界

## 无剧透入口

候选人只打开 [`candidate-brief.md`](candidate-brief.md)。主持人依据 [`interviewer-brief.md`](interviewer-brief.md)逐轮释放连接器清单、事故和销售压力。

## 训练价值

“抽象一个统一 Connector 接口”很容易说，难点是哪些行为真正通用：身份、认证、游标、删除、速率限制、schema 演进、重试、观测和退出；又有哪些必须留在源适配和客户配置。本案例观察候选人能否在交付速度与平台化成本之间做有证据的选择。
