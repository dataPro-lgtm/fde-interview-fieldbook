# 第一轮证据：当前原型数据流

```text
中国文档平台 ----\
                    -> 单一区域对象存储 -> 单一向量索引 -> 外部模型 API
日本文档平台 ----/                                  |
                                                     v
                         集中日志：完整 prompt、片段、回答、用户邮箱
```

- 中国设备手册、供应商问题、员工备注混在同一索引；
- 日本质量流程、客户升级记录、会议纪要混在同一索引；
- 用户通过集团 SSO 登录，但检索层只按部门过滤；
- 中央支持团队可以查看完整日志；
- 原型日志保留 180 天，没有字段级删除；
- 模型 API 使用集团共享密钥，供应商数据保留配置尚未确认。
