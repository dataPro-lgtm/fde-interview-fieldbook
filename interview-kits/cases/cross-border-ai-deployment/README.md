# Field Case Lab：跨境企业 AI 部署

> **场景：** 中国与日本团队共用知识助手，数据边界和运营责任不清
> **时长：** 90 分钟
> **主要观察：** 数据分类、区域边界、最小化、身份权限、供应商控制、分阶段交付与责任治理

## 无剧透入口

候选人只打开 [`candidate-brief.md`](candidate-brief.md)。主持人按 [`interviewer-brief.md`](interviewer-brief.md)释放合成数据流、控制矩阵和压力条件。

## 训练价值

跨境项目不是在架构图上画两个 region。候选人需要先确认哪些数据、为了什么目的、由谁访问、在哪处理和保留，再与客户的法务、安全、数据 owner 共同形成可执行控制。本案例是工程判断练习，不提供法律意见。
